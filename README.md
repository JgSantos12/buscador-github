# Buscador de Perfis do GitHub

Projeto de portfólio, desenvolvido com HTML, CSS e JavaScript puros. Consiste num site simples, que consome a API do GitHub, nele o usuário digita o nome de usuário a ser buscado e o website retorna o perfil do usuário no GitHub, contendo nome, username, biografia, empresa, quantidade de repositórios e data de criação da conta, além de permitir que o usuário vá diretamente ao perfil da conta buscada no GitHub.

## Tecnologias Utilizadas:
* HTML
* CSS
* JavaScript
